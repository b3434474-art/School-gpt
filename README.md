# SchoolGPT 🎓

A free, mobile-friendly school text + voice assistant.

## Features
- Text chat interface
- Voice input with the browser's Web Speech API when supported
- Spoken replies with Speech Synthesis
- School-focused starter answers and study help
- Installable PWA manifest
- No subscription and no API key required

## GitHub Pages
This repository is designed to run as a static GitHub Pages site. GitHub Pages publishes HTML, CSS, and JavaScript from a repository. See the official GitHub Pages documentation: https://docs.github.com/en/pages

After enabling Pages for the `main` branch, the project site will be available at:
